## 线路和速度：差距主要体现在晚高峰

白天两家速度差距不明显，差距在晚高峰：搬瓦工走三网优化线路，Vultr 走普通国际线路，晚高峰丢包、卡顿是常见现象。

搬瓦工提供的国内优化线路包括电信 CN2 GT、CN2 GIA，香港 CN2 GIA，日本 CN2 GIA，日本软银，联通 9929 等，电信、联通、移动三网都有对应的优化回程。Vultr 的机房基本走 NTT 等普通线路，没有针对中国大陆做过优化，电信用户晚高峰时段容易遇到丢包和速度波动。

拿日本机房做个直观比较。搬瓦工日本机房在大阪，走软银线路，带宽 2.5Gbps 起步；Vultr 日本机房在东京，走 NTT，1Gbps 带宽。公开测评数据显示，搬瓦工大阪机房全国平均延迟约 79ms，其中电信平均 71.7ms、联通 74.3ms，移动偏高（约 138ms），电信线路扩容后丢包率已大幅改善。同样选日本机房，搬瓦工的延迟和速度都明显占优。

再往高端走，香港和东京的 CN2 GIA 机房延迟可以做到 30–60ms，这个水平跟访问国内服务器差不多，Vultr 没有对应的产品线。

**已经在用 Vultr，还有必要换搬瓦工吗？**
看用途。晚高峰访问卡顿、丢包明显，且服务器主要服务国内访问，换优化线路的提升立竿见影；机器在海外服务海外用户、用着没毛病，就没必要折腾迁移。
